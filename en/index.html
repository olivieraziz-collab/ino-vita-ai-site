The judge panel

Judges per draft
4
Model families required
4
Author allowed to judge

Independent models re-read every outgoing draft. A model is never allowed to grade its own output, and a missing judge invalidates the whole quorum rather than lowering it.

Outbound network control

Default posture
Deny
Allow-list
Explicit
Refusals logged

The fleet reaches the open internet through one proxy with an allow-list. Everything else is refused and written to the log, whether or not an agent asked for it on purpose.

The quality floor

Default bar
9.5 / 10
Sensitive files
9.8 / 10
Editable downward
No

The floor is compiled in. Lower the bar in the configuration file and the code refuses to read it. One fact that does not match its source blocks the send on its own, whatever the score.

The rule

Nothing goes out and nothing gets paid without your GO.

The agents read, cross-check and do the math. The last decision stays a human gesture — yours. Every financial connector we hold is read-only: the system has never moved a dollar, and it cannot.
